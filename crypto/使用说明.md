# Crypto 加密工具包使用说明

## 简介

`crypto` 包提供安全默认边界下的对称认证加密、密码哈希与密码复杂度策略：

- **AES-GCM 认证加密**：支持标准 / URL 安全 Base64 编码，支持附加认证数据（AAD）绑定业务上下文；拒绝不安全的 `ModeCFB` 及未初始化实例。
- **密码哈希（Argon2id / scrypt / bcrypt）**：在执行 KDF 计算前严格校验内存、迭代次数、并行度及编码长度上下限，防止恶意哈希串触发 CPU/内存 DoS。
- **并发安全的密码策略（`PasswordPolicy`）**：采用不可变配置快照（`atomic.Pointer`）并按 Unicode `rune` 统计长度。
- **CSPRNG 随机字节与恒定时间比较**：`GenerateRandomBytes`（上限 1MiB）与 `SecureCompare`。

## 快速开始

### 1. AES-GCM 认证加密（推荐绑定 AAD）

> 密钥长度必须为 16、24 或 32 字节（推荐 32 字节 AES-256），且必须来自 CSPRNG 或 KMS。

```go
package main

import (
	"fmt"

	"github.com/iwen-conf/utils-pkg/crypto"
)

func main() {
	key, err := crypto.GenerateRandomBytes(32)
	if err != nil {
		panic(err)
	}

	encryptor, err := crypto.NewAESEncryptor(key)
	if err != nil {
		panic(err)
	}

	// 基础加解密
	ciphertext, err := encryptor.Encrypt([]byte("Hello, sensitive data!"))
	if err != nil {
		panic(err)
	}
	plaintext, err := encryptor.Decrypt(ciphertext)
	if err != nil {
		panic(err)
	}
	fmt.Println(string(plaintext))

	// 推荐：使用 AAD 绑定记录归属（如用户 ID），防止攻击者将用户 A 的密文复制到用户 B 名下
	aad := []byte("user_id:10086")
	boundCipher, err := encryptor.EncryptWithAAD([]byte("6222-0000-1234-5678"), aad)
	if err != nil {
		panic(err)
	}
	boundPlain, err := encryptor.DecryptWithAAD(boundCipher, aad)
	if err != nil {
		panic(err)
	}
	fmt.Println(string(boundPlain))
}
```

如需 URL 安全 Base64 编码，可使用 `EncryptWithOptions(pt, crypto.EncodingURLSafe)` 或 `EncryptWithAADAndEncoding(pt, aad, crypto.EncodingURLSafe)`。

### 2. 密码哈希与验证（推荐 Argon2id）

所有哈希器统一实现 `PasswordHasher` 接口：

```go
package main

import (
	"fmt"

	"github.com/iwen-conf/utils-pkg/crypto"
)

func main() {
	argon2Hasher, err := crypto.NewArgon2Hasher(crypto.DefaultArgon2Params())
	if err != nil {
		panic(err)
	}
	scryptHasher, err := crypto.NewScryptHasher(crypto.DefaultScryptParams())
	if err != nil {
		panic(err)
	}
	bcryptHasher, err := crypto.NewBcryptHasherChecked(crypto.BcryptCostDefault)
	if err != nil {
		panic(err)
	}

	hashers := []crypto.PasswordHasher{argon2Hasher, scryptHasher, bcryptHasher}
	password := []byte("MyStr0ng!Pass")

	for _, h := range hashers {
		encoded, err := h.Hash(password)
		if err != nil {
			panic(err)
		}
		ok, err := h.Verify([]byte(encoded), password)
		if err != nil {
			panic(err)
		}
		fmt.Printf("%T -> verified=%v\n", h, ok)
	}
}
```

> **注意**：
> - `bcrypt` 标准限制密码明文不超过 72 字节（超出将返回错误）；长口令场景请优先选择 `Argon2id`。
> - `BcryptCostLow`（成本 4）**仅供单元测试使用**，严禁用于生产环境密码存储。

### 3. 并发安全的密码复杂度策略（`PasswordPolicy`）

`PasswordPolicy` 通过值对象 `PasswordPolicyConfig` 初始化或原子更新，支持高并发无锁校验：

```go
cfg := crypto.DefaultPasswordPolicyConfig()
cfg.MinLength = 10
cfg.MaxLength = 64
cfg.DisallowWords = []string{"password", "admin", "123456", "qwerty"}

policy, err := crypto.NewPasswordPolicy(cfg)
if err != nil {
	panic(err)
}

if err := policy.ValidatePassword("Secur3#Passphrase"); err != nil {
	fmt.Println("密码不符合策略:", err)
}
```

动态更新策略可使用 `policy.SetConfig(newCfg)` 或 `policy.SetDisallowWords(words)`。

## 参数安全边界

- **Argon2**：`Memory` 8 MiB–256 MiB（单位 KiB）、`Iterations` 1–10、`Parallelism` 1–16、`SaltLength` 16–64、`KeyLength` 16–64、编码串 `<= 4096` 字节。
- **scrypt**：`N` 为 `> 1` 的 2 次幂，`128 * N * R <= 256 MiB`，`R` 1–32，`P` 1–16，`SaltLength`/`KeyLength` 16–64，编码串 `<= 4096` 字节。
- **AES-GCM**：仅接受 `ModeGCM` 与 16/24/32 字节密钥；构造期预计算 `cipher.AEAD`，对 `nil` 或零值 `AESEncryptor` 调用返回 `ErrUninitializedEncryptor`。
