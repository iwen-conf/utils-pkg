# signedurl 包使用说明

## 简介

`signedurl` 包提供基于 HMAC-SHA256 的 **v2 规范请求签名 URL** 构建与验证能力，用于临时下载链接、回调地址防篡改等场景。

### 安全契约

1. **v2 规范签名（`_sigv=2`）**：签名绑定 `version`、HTTP `Method`（大写）、`scheme`（小写）、`host`（含端口，小写）、`escaped path` 与去除 `_sign` 后的排序查询串；默认不回退任何旧版签名格式。
2. **密钥强度**：签名密钥按字节计**至少 32 字节**（不足返回 `ErrSecretKeyTooShort`）。
3. **强制过期时间**：URL 必须包含正整数 `_ts` 与 `_exp`；验证方的 `maxAgeSeconds` 只能收紧有效期，不能放宽 URL 自身签名的 `_exp`；允许最多 300 秒未来时钟漂移。
4. **URL 约束**：仅允许绝对 `http` / `https` URL，拒绝相对路径、空 Host、UserInfo（`user:pass@`）及保留参数冲突（`_sigv`、`_ts`、`_exp`、`_sign`）。
5. **一次性消费说明**：本包为无状态签名校验；如业务要求链接“点击一次即作废”，请在业务侧结合 Redis/数据库消费记录实现。

## 快速开始

### 1. 构建并验证 GET 签名 URL

```go
package main

import (
	"fmt"

	"github.com/iwen-conf/utils-pkg/signedurl"
)

func main() {
	secretKey := "0123456789abcdef0123456789abcdef" // 至少 32 字节

	signedURL, err := signedurl.NewURLBuilder("https://api.example.com/files/report.pdf", secretKey).
		AddParam("uid", "1001").
		SetExpiration(1800). // 30 分钟有效
		Build()
	if err != nil {
		panic(err)
	}

	valid, err := signedurl.ValidateSignature(signedURL, secretKey, 1800)
	if err != nil || !valid {
		panic(err)
	}
	fmt.Println("验证通过:", signedURL)
}
```

也可以使用便捷函数 `signedurl.CreateSignedURL(baseURL, secretKey, params, expireSeconds)`。

### 2. 绑定指定 HTTP 方法（如 POST / PUT 上传预签名）

```go
secretKey := "0123456789abcdef0123456789abcdef"

uploadURL, err := signedurl.NewURLBuilder("https://upload.example.com/objects/avatar.png", secretKey).
	SetMethod("PUT").
	SetExpiration(600).
	Build()
if err != nil {
	panic(err)
}

// 验证时必须传入一致的 HTTP 方法；若用 GET 请求重放该 PUT 链接，将返回 ErrInvalidSignature
ok, err := signedurl.ValidateSignatureWithMethod(uploadURL, "PUT", secretKey, 600)
```

### 3. URL Fragment 说明

`#fragment` 属于浏览器端锚点，不会随 HTTP 请求发送到服务端，因此 `SetFragment` 设置的片段会附加在生成的 URL 末尾，但**不参与服务端签名计算**。
