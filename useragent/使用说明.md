# User-Agent 解析工具使用说明

## 简介

本包对 HTTP `User-Agent` 做**启发式展示分类**：猜测常见浏览器名称和版本，并给出 `IsBrowser` 这类展示字段。

User-Agent 可由客户端任意填写。识别结果**不是安全判定**，不得用于登录、鉴权、权限、风控、封禁、支付或“可信 bot / 爬虫”决策。非浏览器也不等于爬虫。

## 主要特性

- 启发式浏览器名称和版本提取（展示用途）
- `IsBrowser` 与 `GetBrowserInfo` 使用同一解析结果
- 内置受限分片强类型缓存（按需懒初始化，超过 `MaxUserAgentLength` = 512 字节的输入不写入全局缓存）

## 安装

```bash
go get github.com/iwen-conf/utils-pkg
```

## 快速开始

### 展示浏览器信息

```go
package main

import (
	"fmt"

	"github.com/iwen-conf/utils-pkg/useragent"
)

func main() {
	ua := "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36"

	isBrowser := useragent.IsBrowser(ua)
	fmt.Printf("启发式 is_browser: %v\n", isBrowser)

	info := useragent.GetBrowserInfo(ua)
	fmt.Printf("名称: %s\n", info.Name)
	fmt.Printf("版本: %s\n", info.Version)
}
```

`IsBrowser(ua)` 等于 `GetBrowserInfo(ua).IsBrowser`。两者都只是启发式展示，不要写成 `is_bot: !IsBrowser`。

空字符串、curl、未知客户端会得到 `IsBrowser=false`，这只表示“没有识别成已知浏览器”，不能当成爬虫或攻击者。

## 边界

1. 本包不做鉴权、风控、反爬或设备指纹。
2. 不要根据 `!IsBrowser` 封禁请求或放行“可信机器人”。
3. 展示层可以使用 `is_browser`、`browser`、`version` 字段；不要映射成 `is_bot`。
