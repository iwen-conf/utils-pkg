# User-Agent 解析工具使用说明

## 简介

本包对 HTTP `User-Agent` 做**启发式展示分类**：猜测常见浏览器名称和版本，并给出 `IsBrowser` 这类展示字段。

User-Agent 可由客户端任意填写。识别结果**不是安全判定**，不得用于登录、鉴权、权限、风控、封禁、支付或“可信 bot / 爬虫”决策。非浏览器也不等于爬虫。

## 主要特性

- 启发式浏览器名称和版本提取（展示用途）
- `IsBrowser` 与 `GetBrowserInfo` 使用同一解析结果
- 可选 LRU / 分片缓存；构造失败立即返回 error
- 无效容量或负 TTL 在构造时失败，不会拖到 Put 才 panic

## 安装

```bash
go get github.com/iwen-conf/utils-pkg
```

## 快速开始

### 展示浏览器信息

```go
package main

import (
    "fmt"

    "github.com/iwen-conf/utils-pkg/useragent"
)

func main() {
    ua := "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36"

    isBrowser := useragent.IsBrowser(ua)
    fmt.Printf("启发式 is_browser: %v\n", isBrowser)

    info := useragent.GetBrowserInfo(ua)
    fmt.Printf("名称: %s\n", info.Name)
    fmt.Printf("版本: %s\n", info.Version)
}
```

`IsBrowser(ua)` 等于 `GetBrowserInfo(ua).IsBrowser`。两者都只是启发式展示，不要写成 `is_bot: !IsBrowser`。

空字符串、curl、未知客户端会得到 `IsBrowser=false`，这只表示“没有识别成已知浏览器”，不能当成爬虫或攻击者。

## 缓存构造

`NewLRUCache` 和 `NewShardedCache` 的第二个参数是 `time.Duration`，不是秒数。构造失败时对象为 nil。

```go
package main

import (
    "fmt"
    "log"
    "time"

    "github.com/iwen-conf/utils-pkg/useragent"
)

func main() {
    cache, err := useragent.NewLRUCache(1000, 30*time.Minute)
    if err != nil {
        log.Fatal(err)
    }
    if err := cache.Put("key1", "value1"); err != nil {
        log.Fatal(err)
    }
    value, found := cache.Get("key1")
    if found {
        fmt.Printf("缓存命中: %v\n", value)
    }

    sharded, err := useragent.NewShardedCache(500, time.Hour)
    if err != nil {
        log.Fatal(err)
    }
    if err := sharded.Put("ua-1", useragent.BrowserInfo{Name: "Chrome"}); err != nil {
        log.Fatal(err)
    }
    _ = sharded
}
```

规则：

1. `capacity <= 0` 返回 `ErrInvalidCacheCapacity`。
2. `ttl < 0` 返回 `ErrInvalidCacheTTL`。
3. `ttl == 0` 表示条目不过期。
4. nil receiver：`Get` 返回未命中；`Put` 返回 `ErrUninitializedCache`。

不要写 `NewLRUCache(1000, 1800)`。`1800` 作为 `time.Duration` 是 1800 纳秒，不是 1800 秒。

## 边界

1. 本包不做鉴权、风控、反爬或设备指纹。
2. 不要根据 `!IsBrowser` 封禁请求或放行“可信机器人”。
3. 展示层可以使用 `is_browser`、`browser`、`version` 字段；不要映射成 `is_bot`。
