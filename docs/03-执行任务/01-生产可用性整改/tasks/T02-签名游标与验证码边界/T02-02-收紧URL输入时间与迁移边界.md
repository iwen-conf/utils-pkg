## 当前行为

1. 空密钥被拒绝，但短密钥可用。
2. `url.Parse` 成功就被视为合法 base URL，相对 URL、空 host、userinfo 和非 http(s) scheme 未被系统拒绝。
3. `_exp` 可缺失或为 0；`maxAgeSeconds` 会在某些路径替代过期时间。
4. reserved query 参数的重复值通过 `Values.Get` 被折叠，可能造成解析歧义。
5. 旧文档宣称防重放，但实现只有时间窗口，没有一次性消费状态。

## 固定错误契约

在保留现有哨兵错误的基础上，新增或重命名为语义明确的哨兵错误，并全部允许标准库 `errors.Is` 判断：

1. `ErrSecretKeyTooShort`：密钥少于 32 字节。
2. `ErrInvalidMethod`：trim 后 method 为空或含空白/控制字符。
3. `ErrMissingSignatureVersion`：缺少 `_sigv`。
4. `ErrUnsupportedSignatureVersion`：`_sigv` 不是 `2`。
5. `ErrMissingExpiration`：缺少 `_exp`。
6. `ErrInvalidExpiration`：解析失败或值不大于 0。
7. `ErrAmbiguousSignatureParams`：`_sigv/_ts/_exp/_sign` 任一不是恰好一个值。

现有 `ErrInvalidBaseURL`、`ErrInvalidTimestamp`、`ErrFutureTimestamp`、`ErrExpiredURL`、`ErrInvalidSignature` 继续使用。

## 固定输入规则

1. secret 使用 `len([]byte(secretKey)) >= 32`；不做字符类别或 Shannon entropy 猜测。
2. URL 必须满足：绝对 URL、scheme 为 http/https、host 非空、`User == nil`、`Opaque == ""`。
3. method 必须是 trim 后的单个 HTTP token；至少拒绝空值、空格、换行和控制字符，再统一为大写。
4. Builder 的 base URL 或业务 params 不得预置 `_sigv`、`_ts`、`_exp`、`_sign`；发现即返回错误，不静默覆盖。
5. 验证 URL 中四个 reserved 参数必须各出现且只出现一次。
6. `_ts` 必须是正整数；`_exp` 必须是正整数秒。

## 固定时间规则

1. `ts > now + allowedTimeDrift` 返回 `ErrFutureTimestamp`。
2. URL 自身截止时间固定为 `ts + exp`；加法必须检查 int64 溢出。
3. `now > ts + exp` 返回 `ErrExpiredURL`。
4. 当 `maxAgeSeconds > 0` 时，再计算 `ts + maxAgeSeconds` 并使用两个截止时间中较早者。
5. 当 `maxAgeSeconds <= 0` 时，只使用签名内 `_exp`；不能表示“永久有效”。
6. `maxAgeSeconds` 大于 `_exp` 时不得放宽；小于 `_exp` 时允许进一步收紧。

## 正向测试

1. 32 字节二进制/十六进制风格密钥均可用，不要求字符类别。
2. 绝对 https URL、显式端口、空 path 规范为 `/` 后通过。
3. `_exp=60` 且 `maxAgeSeconds=30` 时，在 30 秒内有效。
4. `_exp=30` 且 `maxAgeSeconds=300` 时，仍只在 30 秒内有效。
5. `maxAgeSeconds=0` 时仍严格使用 `_exp`。

## 反向测试

1. 31 字节密钥、空 method、带换行 method、相对 URL、`mailto:`、空 host、userinfo、opaque URL 全部失败。
2. 缺失 `_sigv/_ts/_exp/_sign` 任一参数均返回对应哨兵错误。
3. `_sigv=1`、`_sigv=3` 均返回 `ErrUnsupportedSignatureVersion`，不进入 legacy 验证。
4. reserved 参数重复两次返回 `ErrAmbiguousSignatureParams`。
5. `_ts<=0`、`_exp<=0`、非数字和加法溢出失败。
6. 未来超过 5 分钟漂移和已过期 URL 失败。
7. base URL 或 `AddParam` 试图注入 `_sign` 等 reserved key 时 Build 失败。

## 不要做

1. 不以“URL 解析成功”替代绝对 http/https 校验。
2. 不捕获错误后返回 `(false, nil)`。
3. 不用 `time.Now()` 多次读取制造边界不一致；单次验证固定一个 `now`。
4. 不为了让旧测试通过而继续接受短密钥或缺失 `_exp`。
5. 不在文档中承诺本包提供授权、限次或防复制能力。

## 完成标准

1. 所有非法输入在 HMAC 计算前失败，错误可用标准 `errors.Is` 分类。
2. `_exp` 永远存在且不能被 `maxAgeSeconds` 放宽。
3. v2 迁移边界写清，默认无 legacy fallback。
4. url 包、race、全量测试和 vet 通过，进度表同步。
