# T06 测试、依赖与发布治理

## 目标

建立可重复的质量门禁和发布事实来源，确保代码、测试、文档、依赖和版本在未来不会再次漂移。

## 已知范围

1. `.github/workflows/`
2. `go.mod`、`go.sum`
3. `README.md`、各包说明、项目根 `AGENTS.md`、`CHANGELOG.md`
4. `main.go` 及版本测试
5. `LICENSE`（仅在用户明确选择后）

## 验收标准

1. PR 自动执行 Go 1.24 与当前稳定版测试，单独执行 race、vet、coverage。
2. 安全关键缺陷有回归测试，总覆盖率达到门槛。
3. 依赖更新后全部门禁通过，govulncheck 无未处理可达漏洞。
4. 文档与实现一致，版本号与候选发布一致。
5. 未获授权前不添加 LICENSE、不 tag、不 push。
