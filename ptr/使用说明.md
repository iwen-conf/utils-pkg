# ptr 包使用说明

## 概述

`ptr` 包提供简洁、零额外堆开销的**泛型指针辅助函数**（Go 1.24+），仅导出 `Of`、`Value`、`Deref`、`Zero` 与 `ErrNilPointer`。

## API 概览

| 函数 / 变量 | 签名 | 行为说明 |
| :--- | :--- | :--- |
| `ptr.Of` | `Of[T any](v T) *T` | 返回指向 `v` 副本的指针（适用于字面量、结构体、自定义类型） |
| `ptr.Deref` | `Deref[T any](p *T, fallback T) T` | 若 `p != nil` 返回 `*p`，否则返回调用方指定的默认值 `fallback` |
| `ptr.Zero` | `Zero[T any](p *T) T` | 若 `p != nil` 返回 `*p`，否则返回类型 `T` 的零值 |
| `ptr.Value` | `Value[T any](p *T) (T, error)` | 若 `p != nil` 返回 `(*p, nil)`，否则返回 `(zero, ptr.ErrNilPointer)` |
| `ptr.ErrNilPointer` | `var ErrNilPointer error` | 解引用空指针时返回的哨兵错误 |

### 使用示例

```go
package main

import (
	"errors"
	"fmt"
	"time"

	"github.com/iwen-conf/utils-pkg/ptr"
)

type UserRole string

type UpdateProfileReq struct {
	Nickname *string
	Role     *UserRole
	Timeout  *time.Duration
}

func main() {
	req := UpdateProfileReq{
		Nickname: ptr.Of("Alice"),
		Role:     ptr.Of(UserRole("editor")),
	}

	// 1. 带自定义默认值的安全解引用
	timeout := ptr.Deref(req.Timeout, 30*time.Second)
	role := ptr.Deref(req.Role, UserRole("viewer"))

	// 2. 零值安全解引用
	nick := ptr.Zero(req.Nickname)

	// 3. 显式区分 nil 的解引用
	_, err := ptr.Value(req.Timeout)
	fmt.Println(nick, role, timeout, errors.Is(err, ptr.ErrNilPointer))
}
```
